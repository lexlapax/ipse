   a pointer, and update the plan/map. Do not rewrite historical copies. Create a
   dated P31A record for concrete decisions, evidence and subsequent amendments.
2. **Map the host gaps to real owners.** Specify versioned turn-local envelopes and
   reconstruction, stable catalog/header epochs, paged source IDs/reads, input-origin
   and explicit-acceptance events, draft/cancel intent transitions, protected consent
   and cross-process publication. Use the source map below. Name the package owning
   each behavior/test; no extension may bypass a required host change.
3. **Freeze and exercise interaction contracts.** Use a small nonpublishing prototype
   for setup-before-chat, next-new-session activation, explicit `accept CODE`, normal
   direct-fact capture with no per-fact approval, standalone terminal review, category
   downgrade and show/replace/accept/cancel enhancement. Recruit a fresh-user tester
   and record naming ambiguities; bare yes remains disabled regardless of convenience.
4. **Freeze the pilot, then measure what is available.** Run the bounded main-route
   capture pilot only under selected finite authorization. Record raw useful intake,
   class/payload mix, misses, duplicates, continuations, cache counters and TTFT.
   Derive capacity/workloads from observed sessions while preserving the initial
   floors. Keep pilot and held-out cases separate. No access means unverified, not
   fabricated measurements; no alternate paid provider may fill the gap silently.
5. **Compare storage/parser candidates.** Evaluate maintained Elixir/OTP facilities
   and packages before custom machinery. Write a decision matrix for sustainable
   notes, evidence/history/suppression and DOCX/PDF boundaries. No library is already
   selected. Inventory chosen dependencies and licenses, honoring the narrow Rust
   PDF exception and separate approval for non-Elixir/Rust dependencies.
6. **Freeze inspectable acceptance.** Record corpus IDs/hashes, source/claim classes,
   exact wire/layout fixtures, cache/latency controls and sample counts, intake and
   retention mix, capacity/resources, burst behavior, native-group/cancellation and
   concurrent-process cases. Follow the design's distinct structural, semantic,
   performance, live and human gates; record remaining access gaps by route.
