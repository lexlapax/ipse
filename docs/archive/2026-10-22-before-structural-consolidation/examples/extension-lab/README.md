# Independent extension lab

These separately compiled artifacts exercise Ipse's public worker SDK. They are
synthetic examples, disabled in generated configuration, and are not production
memory, graph or retrieval engines. Building them does not install or enable them.

Use the [operator walkthrough](https://github.com/lexlapax/ipse/blob/5bffe00364d66f5012e5a0d4cd86c4180c74ebcb/docs/operator/extension-lab.md) to build,
review, import and run the lab. The [developer proof](https://github.com/lexlapax/ipse/blob/5bffe00364d66f5012e5a0d4cd86c4180c74ebcb/docs/developer/testing.md#learn-a-complete-workflow-through-the-compatibility-lab)
owns architecture, verification scope and future capability limits. Artifact
licenses are copied from the repository license by the explicit builder.
