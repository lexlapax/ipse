# Public-Session evaluation orchestration, 2026-10-19

Historical implementation and fixture record after `579f609`. The commit
containing this record owns the runner, prediction-format change and optional
Research time argument. Use the current [evaluation training chapter](../../developer/knowledge-evaluation.md)
and [Research user procedure](../2026-10-22-before-structural-consolidation/docs/operator/research-extensions.md) for current
instructions. The [plan](../../plan.md#p27-optional-research-graph-and-rag) retains
the complete acceptance scope. This increment does not complete P27.

The maintained runner selects independently built artifacts and invokes their
public commands through Session. A separate process prepares source-only chunks
and explicit facts; production domain modules remain absent from the harness VM.
Query projection excludes label values. A fixed variant plan selects algorithms,
profile destinations, shared-store bindings, first-attempt rows and finite budget
allocations. It forbids implicit lexical fallback in the matched hybrid variants.
Fixture mode accepts only explicitly named synthetic models on alternate loopback
ports. Actual execution requires the declared existing local model inventory.

Preparation ingests source generations and applies explicit suppression before
indexing or extracting current eligible sources. Each invocation records its new
receipts, including individual paged source operations. An invocation that never
dispatches cannot borrow an older receipt. Effect checks bind the selected
artifact, command owner, profile, complete egress and per-invocation call counts.
Research fetches only the current search result's selected URIs. The controlled
gateway retains its global call ceiling across document/project changes.

Research accepts optional integer `as_of_ms` so the comparison can use one time
across all seven variants. Omitting the argument preserves current time selected
after capture. The isolated regression covers observation before/at the selected
time, expiry before/at it and invalid times. This changes source eligibility; it
does not establish a historical version of remotely fetched content.

Version-two prediction rows preserve the complete retrieval ranking separately
from cropped answer-context citations. Context spans must be contained in ranked
evidence with identical source identity and bytes. Retrieval and annotated-span
measurements continue to use the original ranking. Semantic citation judgments
can refer to the actual answer context. Legacy rows, foreign/uncontained context,
duplicate identifiers and incorrect hashes refuse before label loaders run.
