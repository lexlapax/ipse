# Manuals before the audience rewrite

Historical reference only. This snapshot preserves the operator/developer documents,
entry points, project plan and public evaluation manifests from commit
`10b9dd66d06ef28718b58530a7e5b01c7c50397a`, dated 2026-10-18, before their rewrite as user and contributor manuals.
It includes original verification failures, repairs, measurements, research and
acceptance records. These records are not current operating instructions.

The original Markdown bodies remain intact apart from relative-link rebasing and
the historical banner. JSON bodies are unchanged. [The manifest](manifest.json)
records each original and archived SHA-256. The current replacements are the
[user manual](../../operator/index.md), [developer training manual](../../developer/index.md)
and [project plan](../../plan.md). Historical milestones must be read with their
recorded source revision, platform, exclusions and limitations.
