# Managed approval and host-operation display refusal

Historical scoped receipt, 2026-10-29. This supersedes the active approval behavior
in [the earlier action/document controls](managed-actions-document.md); their
tested cohorts remain historical. Current milestone status remains in
[the plan](../../plan.md). This is not P31C0 acceptance.

Managed source-derived arguments cannot be queued for an ordinary approval or
question until the complete display can occur through an output sink that holds
the actual source and Consent leases. A BEAM precheck followed by subscriber
rendering does not establish that boundary. Turn and Invocation now refuse such
managed proposals before the full argument notification. Existing queued managed
approvals cannot grant execution or reusable permissions. Ordinary untainted
approval still displays the complete proposed arguments.

Extra managed tool progress contains no arguments. Managed calls to skill loading,
research records, saved-result reading and model-facing source tools refuse before
their unproved host operation. This preserves their ordinary paths and does not
pretend that final result validation authorizes the earlier operation.

Strict compilation of the three changed modules passed in 46850. The six focused
actual Session controls passed across 46851 and 46852:

- Current managed extension approval refused before display or effect.
- The same refusal held after a changed root before the prompt.
- Actual source Writer loss stopped the Session without a later approval or effect.
- Managed model write approval queued no arguments and started no tool.
- Managed `source_list` entered no unqualified host operation.
- Ordinary untainted extension approval displayed full arguments and could be declined.

The first three controls passed in 46851. The other three failed during artifact
admission because a shared synthetic artifact declared document storage without
its binding. Splitting the document artifact repaired the fixture; only those
three unexecuted controls were rerun in 46852 (3 passed, 5.7 seconds).

The exact remaining boundaries are a leased full-argument display sink; actual
owner-fenced IO for the refused host branches; managed delegation child start;
and owned release of managed nested action results into the worker pipe. Existing
file/shell/MCP current-use implementations still require the shared native lease
ownership audit. Supersession display remains separately disabled. None of these
paths is qualified by the present refusal controls. Original-source lease loss,
legacy resumed questions and arbitrary sink scheduling need their own review.

The [independent review](managed-host-display-independent-review.md) found
legacy pending-question disclosure and unfenced managed State and service
operations, plus a two-source publication candidate. Those findings remain open
until their repairs and focused controls are complete.

The [manifest](managed-host-display/manifest.json) freezes the source, logs and
complete runtime inventory. Its notes distinguish the final unselected fixture
changes and retained runtime dependencies. No PTY or aggregate suite was run.
