## Actual release path

After closing the worker, the original owned Host task prepares one exact inline
result or sealed paged descriptor in Session. The owner binds the actual parent,
action sequence, raw result digest, complete host-derived inherited/read union,
Session job and original task. It records a release intent and the raw historical
result privately. Neither raw result recording nor a preflight verdict authorizes
delivery. Managed context contributions remain staged too.

Outside the Session GenServer, the existing ManagedUse boundary reacquires
original source leases, current identity, Consent, policy, collection and literal
validity for that complete union. Its callback calls the exact current owner to
record causal admission and publish the actual tool text, command/service display
or context publisher. This reuses the phase-bound source snapshot interface;
workers cannot select dependencies or supply release authority.

Current tool delivery checks strict `now < deadline` again after its last tool
message journal write and immediately before notification. A deadline crossing
during that write preserves the historical record but emits no raw tool text.
The original task records confirmed or unknown cleanup afterward. A callback may
already have published when later source/native cleanup fails; the unknown path
does not retry, fall back or claim that no delivery happened.

If current authority is unavailable before entering publication, ordinary worker
content is replaced by a fixed host withheld notice. For a self-writing capture,
the host may instead render only historical write facts reconstructed from exact
committed managed actions, normalizations and receipts. The original worker
result retains its complete read union; arbitrary reads are never dropped or
rebased. These historical write facts explicitly do not establish current note
eligibility.

## Journal and reconstruction

Fresh Session headers declare `managed_output_release_v1`; null or unknown
declarations refuse. Actions and ManagedLineage validate intent, actual raw result,
admission, actual host projection and cleanup in causal order. Historical tool
projection is bound to the exact validated raw-result digest and a chronologically
seen admission, including its actual parent request and call. Byte equality alone
does not identify a producer. Missing, duplicate, reordered or mismatched release
records refuse or leave managed lineage unavailable.

An interrupted prefix or unknown cleanup reconstructs a withheld tool notice and
unavailable lineage; it cannot resume pending publication. Context publishers
become eligible in reconstructed context only after confirmed cleanup. A paged
result is recorded separately from its readable committed source: both the
pre-admission and post-admission/pre-cleanup prefixes keep the sealed bytes
private. Confirmed current cleanup publishes the immutable historical descriptor.
Later explicit `/result` or materialization is historical inspection, and later
model use retains the original dependency union and separate current-use gate.

The retained release lookup refuses above 2,048 entries or 4 MiB rather than
silently evicting source/result bindings. Other existing context, journal,
dependency and source-scan bounds remain applicable.
