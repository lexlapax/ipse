regardless of original call dependencies. Session accepts preparation only from
the exact current task/job/tool phase, matching call name and decoded arguments.
Writer accepts its private query only from the actual Session owner. The private
SourceWindow query validates its pending original call, resolves the actual
SourceIndex result and returns all selected occurrence/version/provenance rows.

occurrence. No source body is published by this classification query.

ManagedLineage resolves selected request/invocation/effect producer IDs through
host-owned maps and a positive committed-producer dictionary. A known producer
with empty lineage is distinguishable from a missing producer. Omitted producer
fields in an authentic original input occurrence are not a worker-provided empty
cache. Workers cannot inject arbitrary selected rows: Writer/SourceIndex derives
them from the validated actual query. Missing mappings or malformed state refuse.

journaled. Its exact operation/request/selection/dependency digests bind one
active call. Only a truly empty or exact cached root-only union may continue.
The actual ordinary task lookup is limited to empty dependencies; a nonempty
lookup additionally requires the exact admitted effect peer, worker/job/binding,
deadline and current root-only union under ManagedUse. The preflight is consumed
once for that actual query. Duplicate preparation/consumption cannot create a
second admitted lookup. Source handles remain bounded own-Session references,
not arbitrary journal or filesystem paths.
