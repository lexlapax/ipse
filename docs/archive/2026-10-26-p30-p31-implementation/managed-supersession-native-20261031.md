## Implemented journey

Interactive `/correct note.HASH TEXT` and `/supersede note.HASH TEXT` now use
the existing statement/category intake, followed by a separate full relation
review. Session chooses the complete escaped facts and fresh challenge for a
typed native v13 purpose. The actual tracked file-effect publisher retains
Identity, Consent, Collection and all active/inactive original sources through
display. Actual Writer drain, exporter settlement and the Session notice precede
thaw; policy/source scopes release before native input begins. No proxy process,
serialized observation or worker-selected display can manufacture a permit.

The normalizer consumes the fresh same-owner permit under reacquired authority.
Collection claims it once for the exact intent, original request, normalized
mutation and normalization receipt. The existing native transaction imports
the actual Session control, original flock, Writer control and every inactive
original source group through `Runner.SessionSource`. Those controls survive
through the final locked root decision. The deadline is bounded by the remaining
30-second review permit and normalized publication policy; it is no promise of
kernel-atomic clock checking or physical rollback.

The obsolete asynchronous review coordinator/proxy was removed. The publisher
now owns the review and effect directly inside its existing resource scope.
Native formats and dependencies are unchanged. Generic unreviewed supersession
remains closed, as do accepted-decision v6 targets and headless replacement.

The genuine Session cohort passed **11 cases in 91.9 seconds**. It covers ordinary and temporal replacement, separate
original/consumer Sessions, relation cancellation, revocation, missing original,
CLI success/cancellation, native input loss, native post-switch control loss,
shared retention/expiry and disabled capture. It checks physical generations,
operation receipts, unchanged historical values, current eligibility, preserved
source history, Saved reconstruction and idle resume without replay. During
input it reacquires the policy locks and inactive original lock while the active
conversation retains its own flock. Shared expiry authenticates signed history
after old object reclamation and uses 13 closed read units.

The post-switch fault case installs an explicitly instrumented SessionSource
BEAM in its isolated child host **before** initial permission review. Its host
identity is stable and covered by that review. The only interposition pauses
after the actual native callback has switched the root and before settlement;
the watcher confirms the generation increment and kills the actual Session
control helper. The test requires unconfirmed delivery, Session shutdown,
unchanged incremented root and successful idle resume without effect/inference
replay. This controlled host is not an unmodified production fault run or an
independent audit. Native helper bytes and root-switch implementation are unchanged.

Earlier failures remain inventoried. They found remember-only intake, a closed
dispatch gate, omitted typed ticket fields, empty inactive-source transport,
and rejection of a genuinely reviewed but pre-effect-refused journal result.
The new refused shape permits only a nil outcome; settled results retain their
complete checks. Fixture repairs account for release-owner markers on close and
resume, a pre-existing retention generation, and a read closure correctly sealed
before publication. An early fault interposition changed the module's code path
after permission review; resume properly refused that host identity. The final
fixture installs its instrumented identity before review instead of relaxing
production integrity checks. A redundant watcher exit timeout was removed;
the parent still requires actual Session exit and successful recovery.
