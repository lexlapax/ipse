## Scope and authority

The independent SDK can request closed collection reads or an eight-change,
8192-byte commit with one to eight source quote requests. Session journals before
reservation/effect, owns the source window and validates the actual worker/job/
action lease. The host rederives stable original-source proofs, chooses exactly
one constrained current mapping from actual request/schema/origins, checks mode
ceilings and publishes under retained ProjectIdentity/Consent/Collection locks.
Known results settle once inside publication; unknown work retains liability.

Public `Ipse.Extension.source_proof/3` is usable in the independent SDK closure.
It constructs untrusted stable evidence JSON; host `SourceIndex.resolve_proof/2`
independently authenticates the actual current quote. File/stdout/external/advice/
legacy capture remains refused without a validated original path boundary.

Protected outer intent/inline version 3, paged final version 4 and typed tool
version 2 retain exact closed semantic bindings. Read/publication class is host
derived. Fresh active semantic-admission version 2 retains the original bounded
reviewed policy and verifies its canonical hash against the pin. Replay derives
the class again. V1 admission resumes inertly and cannot enter a new protected
outer. A read outer categorically denies every mutating inner action, including
under `--yes`; no legacy/event-job parent can borrow this increment's outer grant.

The correction-floor repair is checked twice: worker admission and protected
CollectionPolicy require `advance_floor: true` for every replacement or deletion.
Fresh unique inserts may keep false. Imported lineage floors are independent of
local generation and are not rewritten to fit a local counter.

No dependencies, provider calls, model downloads or private qualification inputs
were added or used. The implementation reuses the existing maintained JSON/schema
adapter, Collection encoding/storage and owned resource/transaction machinery.
