# Inherited root metadata in capture — independent direction

Read-only requirements/source review, 2026-10-29. **Allow the complete inherited
input only when every member of the complete publication union is an authentic
cached payload-free root observation.** Removing the empty-input restriction
under that exact condition is supported by the original capture contract.
This is a narrow extension of the [causal-cache review](causal-root-cache-independent-review.md),
not permission for inherited record content. No code, tests, Saved replay,
effects or provider requests were run or changed here. The [plan](../../plan.md)
owns acceptance.

## Requirement and smallest change

The [baseline](baseline.md#capture-with-the-selected-main-model) expressly calls
for the selected main model to capture useful source-bound receipts during the
same turn, including eligible typed host outcomes under saved headless consent.
It requires host source ownership, exact support, exclusions, lineage and current
consent. It does not require an empty recall root's authentic metadata to vanish
from the next model-selected tool invocation. Such metadata identifies the
current root/policy/CAS prerequisite; it carries no stored note payload.

`ManagedToolUse.invocation_union` already validates the exact active invocation
parent and available ManagedLineage, then unions decoded inherited `entry.input`,
all accumulated reads and current invocation managed reads. Decoding uses
`Map.fetch!` on the host dictionary. The publication predicate catches missing
entries/errors and refuses. Keep this union intact. Do not drop inherited IDs,
replace them with own nil gets or infer absence of content from the v3 label.

For a nonempty union, the existing positive-cache/full-root/pin/expected-generation
predicate must apply to **every** member, including every decoded inherited ID.
Under that condition, `entry.input == []` adds no source-policy protection for
the reported payload-free root case and may be removed. No separate weaker
inherited allowlist is needed: the complete union is the allowlist boundary.
Missing cache/dictionary, non-`true` classification or unavailable lineage fails.
Retain exact same-Session host classification, project/namespace/pin/epoch,
identical complete root map, and requested expected generation. Changed roots
cannot be rebased, and nonempty index/value/scan/record dependencies do not pass.

Preserve existing own fresh prerequisite reads and actual normalizer/source
validation. Final actual Identity/Consent ownership, current policy/source
generation, Source proof/unique exact quote, category/retention/exclusion checks,
normalizer root witness and Collection CAS remain unchanged. The cache is only
historical classification; it cannot authorize publication by itself. No new
synthetic snapshot operation or key-prefix restriction is necessary just to
qualify these already authenticated roots.

This changes no interpretation of worker arguments or source text. A main model
may supply arbitrary capture arguments, but the existing Host must still derive
their source class and match exact authenticated support. The root-only condition
does not promote copied receipts, arbitrary file prose, unattended assertions,
assistant claims or inherited managed record bytes. Content-bearing input would
require a separately qualified path; this change does not supply one.
