# Ipse v0.1.0

Ipse is an Apache-2.0 general-purpose local AI harness with a coding-oriented
prototype. Elixir/OTP owns conversations, approvals, durable intent, providers
and optional extensions. Small Rust helpers own OS facilities.

## Install and start

Download the archive for Linux x86_64 or macOS arm64 and its SHA256 sidecar below.
Follow the [installation manual](https://github.com/lexlapax/ipse/blob/v0.1.0/docs/operator/install.md)
to verify the checksum, install the bundled runtime and run `ipse setup`,
`ipse doctor` and the credential-free `ipse demo`.

## Included

- Interactive chat and one-shot tasks, journaled file/shell tools and recovery.
- Explicit ChatGPT subscription, OpenAI API, Ollama, Anthropic API, Gemini API,
  pinned OpenRouter API and loopback-compatible routes. Provider and billing
  choices never fall back silently.
- Grok API-key and registered-client OAuth routes, verified with fixtures.
  Live API inference remains unverified after HTTP 403. OAuth requires an
  approved Ipse registration from xAI and an eligible subscription.
- Native workspace-edit and exact-shell-call session grants with inspection and
  revocation. Children, MCP and extension effects retain separate approvals.
- Opt-in local children, MCP and optional built-in or independently built extensions.
- Offline diagnosis, explicitly requested metadata probes and build identity.

## Limits and upgrades

Bundles include ERTS and native helpers; checksum sidecars are separate assets.
The bundles are unsigned and unnotarized. Windows and package-manager distribution
are outside this release.
Linux requires compatible libc and libraries. Native Linux confinement requires
the documented kernel and namespace facilities; macOS confinement is experimental.
Doctor's availability check does not prove kernel enforcement. Read the
[shell policy and cancellation limits](https://github.com/lexlapax/ipse/blob/v0.1.0/docs/operator/usage.md#choose-shell-confinement).

MCP treats every nonempty configured environment value as private. Very short
values can collide with public metadata and refuse configuration before a server
starts; see [MCP configuration](https://github.com/lexlapax/ipse/blob/v0.1.0/docs/operator/mcp.md#set-a-local-servers-permissions).

Selected extensions bind the host BEAM build. Finish their sessions or retain
the old release for resume/export before upgrading. Extension-free sessions
require matching configuration. A mismatch refuses before work; journals are
not silently migrated. Follow the
[upgrade and rollback procedure](https://github.com/lexlapax/ipse/blob/v0.1.0/docs/operator/install.md#upgrade-without-losing-recovery-options).
Credentials never come from another application's token store. API billing and
subscription access remain separate.
